This PHP Dynamic App is a web application that manages records in a MySQL database named dynamic_project, and can be found in C://users/XAMPP/htdocs/assign1. It provides CRUD functionality: Create, Read, Update, and Delete. The Create functionality allows records to be created using a PHP form.
 The form validates user inputs and ensures that there are no empty fields and once that is done, it adds the record to the database (using prepared statements for security). The Read functionality simply reads all records and displays them on the browser formatted into an HTML table. It pulls the data dynamically from the database to show users the records in a friendly format. The Update functionality allows the user to update existing records by filling in a form with the current record details and upon clicking submit, it saves to the database with prepared statements for security.
 The Delete functionality allows records to be deleted from viewing by confirming the deletion and safely deleting with prepared statements help filter inadvertent deletions. The application separates the connection to the database, crud logic, and frontend into separate files to help with maintainability of the project. 

 use phpMyAdmin to import dynamic_project.sql to create the database and accompanying tables along with sample data. Next, copy the php file associated with this assignment and place them in the htdocs/assign1 directory. You need to update your db_connect.php with your mysql credentials before viewing the web application. Additionally, please start the engine of apache and mysql server in XAMPP. You will then need to point a browser to the address http://localhost/assign1 to test the crud.
